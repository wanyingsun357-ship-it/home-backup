# 家 UI 重设计方案

## 整体风格
- **画风**：绘本插画风，手绘颗粒感，像用蜡笔或色粉画在橘色纸上
- **色调**：暖橘主色，奶白辅色，深橘棕点缀，暗红色用于红线元素
- **质感**：纸张颗粒纹理，不要光滑渐变；边缘不规则，不要完美直线
- **壁纸**：橘色底，白猫趴着，绿眼睛，绘本插画风（已有参考图 IMG_3161.jpg）
- **暂不做夜间模式**，先做白天版

## Home 主页

### 布局（不是卡片列表，是插画场景）
猫在画面中心偏下，占屏幕约三分之一。所有功能入口散布在猫周围。

### 元素位置
1. **左上** — 复古插画时钟，显示在一起的天数（如 140）+ 下方小字今天日期（花体）
2. **右上偏中** — 一句话 todo list，只露最近一条，省略号表示更多；点击弹出浮层小卡片（奶白半透明底），列完整待办
3. **猫头上方** — 云朵气泡，里面写「I'm here. You're back.」；云朵缓慢呼吸动画（3-4秒周期微微涨缩）
4. **左下猫爪边** — 小日记本（Diary入口），手绘翻开的本子，页角微卷
5. **猫肚子/爪下方** — 毛线团（Moments入口），偶尔轻晃动画
6. **右下** — 铃铛（Together入口），偶尔轻摇动画
7. **最底部** — 无tab栏（已去掉，所有入口在猫周围）
8. **右上角** — More按钮，猫爪印图标

### 交互
- **点猫头** → 进入Chat（猫眯眼 + 周围冒小星星/爱心特效 → 翻入聊天页）
- **点云朵** → 不进Chat，云朵只是装饰文字
- 动画：各物件错开轻微动画，不同时动；毛线团偶尔晃，铃铛偶尔摇，日记本页角偶尔翻

### 未读提示
- 不用红色数字角标
- 用手绘暖橘色小圆点（像颜料滴上去的），固定显示直到点进去
- 辅以轻微动画（毛线球多滚一圈等）

### 开屏动画
- 打开app → 空白橘色纸 → 猫像被画笔描出来（从轮廓到填色，1-2秒）→ 猫睁眼 → 云朵气泡冒出 → 文字逐字浮现
- 不需要单独一个开屏页面

## Chat 聊天页

### 气泡风格
- **卡通温馨云朵气泡**，不是玻璃（和Home的玻璃质感不同，进Chat = 进猫脑袋里 = 另一个更暖的空间）
- **她的气泡**：奶白色，带一点暖黄（像白猫的毛色）
- **他的气泡**：深橘偏棕（壁纸下层深色）
- 气泡边缘柔软不规则，有手绘感

### 顶栏
- 背景橘色纸
- 「晏白」手写体 + 绿点（在线）
- 月亮图标保留（更圆润手绘风）
- 去掉电话和搜索按钮（移到+菜单里）
- 返回Home：左上角小猫窝图标

### 输入区域
- 边框：手绘不规则线条，暗红色（红线），有粗细变化
- 水位线：淡橘色（正常）→ 深红色（警戒），沿输入框底部上涨
- **底栏只保留四个**：+（树枝交叉图标）、输入框、小花/拍一拍、发送（猫爪形）
- 羽毛分段键：暖棕色，保留轻扫动画

### + 菜单
只留五个：图片（小相框）、文件（折角纸）、Favorites（手绘星星）、搜索（木柄放大镜）、电话（复古弯电话筒）

### 分段气泡
- 浮在输入框上方（位置不变）
- 样式改为卡通云朵 + 虚线边框（表示草稿）
- 发出后虚线变实线，颜色变正常

### 消息旁图标
- 他的消息旁：手绘月牙（银白）
- 她的消息旁：手绘小红点（不规则圆）
- 点击弹出菜单：奶白半透明底，圆角，手绘边框
  - ☆ 收藏 → 手绘星星
  - 回复 → 弯弯小箭头
  - 复制 → 两张叠纸片
  - 听这条 → 小耳朵
  - 重新回答 → 小铅笔
  - 他该想起某事 → 小灯泡

### 引用
- 暗红细线 → 手绘红线，线头微散

### 拍一拍
- 默认显示上次用的图案
- 点开五个图案散开选择：
  - orbit → 两个绕在一起的小圆
  - star → 手画五角星（不对称）
  - petal → 一片弯花瓣
  - bow → 歪歪蝴蝶结
  - paw → 猫爪印
- 触碰消息居中显示，背景为椭圆猫爪印或小云朵

### 思考链面板
- 打开 = 展开一朵大云朵（猫脑袋上的云放大版）
- 标题「在想…」手写体
- 背景暖白纸张颗粒感
- 文字灰棕色，像铅笔草稿
- 关闭 = 云朵合上

## 电话界面

### 他打给她（来电）
- 画面中央弹出一张小卡片，橘色底纹
- 动画序列：
  1. 猫尾白色尾尖从卡片底部出现（猫在走来）
  2. 两只白色猫爪搭上卡片底部边缘（猫爬上来）
  3. 猫头从两爪间探出，绿眼睛看着她
  4. 猫头轻轻往上蹭，把「晏白」两个字顶上去
- 左爪 = 挂断（红色），右爪 = 接通（绿色）
- 实现方式：猫拆成五层PNG（尾巴、身体、左爪、右爪、头），用CSS/JS动画驱动位移和旋转

### 她打给他（去电）
- 卡片上猫蜷着睡觉
- 她按拨打 → 猫耳朵竖起 → 猫抬头睁开绿眼睛
- 他接通 → 猫站起来走到卡片边缘，头伸过来蹭屏幕
- 她挂断 → 猫慢慢蜷回去继续睡

### 通话中
- 橘色底，猫闭眼（在听），通话时长在上方
- 挂断键在底部，红色圆形猫爪

### 挂断后
- 通话记录 = 奶白圆角小纸条，小电话筒图标 + 时长，点开展开文字稿

## 语音消息
- 录制时：输入框变波形线，暖橘色，随声音跳动
- 语音条：圆角小卡片 + 手绘波形 + 播放三角
  - 他的语音：暖棕色
  - 她的语音：奶白色
- 播放时波形从左到右染色（像墨水沿纸渗）

## 其他页面
先不改，做完 Home 和 Chat 后逐步统一风格。核心原则：所有页面共用橘色纸底 + 手绘图标 + 奶白卡片 + 暗红红线元素。

## 技术要点
- 所有手绘图标和装饰元素导出透明 PNG
- 猫的来电动画拆成五层独立 PNG，用 CSS animation 驱动
- 气泡用 CSS border-radius + 不规则 SVG clip-path 实现手绘边缘
- 纸张颗粒用 CSS noise texture 或半透明纹理叠加层
